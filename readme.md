## About

I build **AI systems that survive contact with production** — agentic RAG pipelines with hallucination
grading, hybrid CNN-Transformer vision models, and the FastAPI/Node services that put them behind a
real endpoint.

Currently a **Software Development Intern at Infosys Springboard**, working on REST APIs, AWS
infrastructure and CI/CD. **AWS Certified Cloud Practitioner (CLF-C02).** Final-year B.E. CSE at
SIMATS University (CGPA 8.74/10).

I care about the unglamorous half of ML: evaluation, grounding, reproducibility, and shipping.

- 🔭 Building **[Self-Corrective RAG Assistant](https://github.com/lokeshtheprogrammer/Langgraph-RAG-Docs-Assistant)** — LangGraph agent loop, live on Hugging Face Spaces
- 🔬 Writing up **[HCT-CBAM](https://github.com/lokeshtheprogrammer/cnnvit)** — hybrid CNN-Transformer for fine-grained food classification, IEEE submission
- 🌱 Going deeper on **LLM evaluation, RAG at scale, and Kubernetes**
- 🤝 Open to **AI/ML Engineer** and **Full-Stack** roles — and to open-source collaboration
- 📫 Reach me at **jlokeshprabu@gmail.com**
